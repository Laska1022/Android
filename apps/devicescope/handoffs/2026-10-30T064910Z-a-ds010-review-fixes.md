## Confirmed fixes

1. RAM/storage total=0, available=0 previously displayed valid zero available bytes
   despite unknown total capacity. Both now validate the pair consistently; a real
   positive-capacity volume with zero free bytes still displays Available(0).
2. Sensor metadata bypassed numeric validation when embedded in TEXT: NaN, infinity,
   negative power and invalid delay could look like measured values. These now say
   unavailable. getMinDelay -1 is one-shot; 0 is non-periodic, not a sampling period.
3. EGL preflight calls were outside the error boundary. Exceptions could fail the
   whole hardware stream. Cleanup could abort after one exception, and ignored false
   release results could still report success. The entire GPU query is now isolated;
   restore, fallback unbind, surface/context/display cleanup are attempted independently,
   failures produce a GPU error, and cancellation is preserved.

Public model signatures, field IDs, units, factory and polling interval are unchanged.
